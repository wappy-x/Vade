$ vade chat --help
Chat with the running engine.

Examples:
  vade chat
  VADE_CONFIG=cluster.conf vade chat

Usage: vade chat [--api-key-file PATH] [--dry-run]

Options:
  --api-key-file PATH  Bearer credential file (or VADE_API_KEY_FILE)
  --dry-run            Show what would happen; change nothing

Notes:
  - Opens the Vade agent on the resident engine. Start the engine once with vade
    launch or vade up.
  - Local contexts below 8192 tokens use direct text chat. Local Linux agent
    mode disables automatic workspace checks with a notice.
  - Typing during a reply interrupts it and keeps its partial answer in context.
    /queue on queues follow-ups; /queue off restores steering. /exit leaves the
    engine running.
  - Chat history is kept in ~/.vade/projects (VADE_HOME changes the root), never
    in this folder; VADE_CHAT_IN_PROJECT=1 keeps it in a git-ignored ./.vade.
  - Explicit VADE_CONFIG selects the controller; otherwise generated local setup
    wins. Keep the same VADE_CONFIG and VADE_HOME from start through chat,
    status, logs and down.
