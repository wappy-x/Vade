$ vade pull --help
Download a model from the Hugging Face Hub.

Examples:
  vade pull nvidia/Qwen3.8-Flash-Next-FP4-Local
  vade pull Qwen/Qwen3-8B --dry-run
  vade pull org/name --include '*.json' --to ~/models/org/name-metadata

Usage: vade pull <org>/<name>[@revision] [OPTIONS]

Options:
  --include PATTERN  Download only matching paths; repeat for more (* matches
                     any text, / too)
  --to DIR           Model folder (default ~/models/<org>/<name>)
  --dry-run          List the files and sizes; download nothing

Notes:
  - Without --include, pull takes the weights (*.safetensors and the index),
    every JSON config, the tokenizer files, the chat template, the README and
    the license. The revision is a branch, tag or commit; the default is main.
    docs/pull-models.md gives the pinned command for each checkpoint Vade
    serves.
  - Every file is checked after download: size, then the SHA-256 the Hub lists
    for large files or the Git blob ID for small ones. Run the same command
    again to continue an interrupted pull; partial files resume.
  - Writes .vade-model.json in the folder (repository, commit, files, sizes,
    hashes, time, license and support state) and <folder>.sha256 beside it,
    which vade launch and vade up check before they serve FP4-Local. Ctrl-C
    stops the pull and writes no records.
  - For a gated or private model, accept its terms on the model page, then set
    HF_TOKEN or save the token in ~/.vade/hf-token. The token is never printed
    or passed on the command line. HF_ENDPOINT names a mirror. Transfers use
    curl from PATH.
