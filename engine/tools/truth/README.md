# Official reference-data provenance

The saved official reference data was generated with the official model code
in Hugging Face Transformers and PyTorch. The generators are retained
privately, outside this repository. They never
run in the engine and are no longer part of the source export.

The maintainers' agent tooling is kept privately, outside this repository.
Reference regeneration requires access to the private oracle and its pinned
environment. The repository retains the
[fixtures](../../fixtures/README.md) and the Rust checks that consume them;
[Validation](../../docs/validation.md) records their methods and limits.
