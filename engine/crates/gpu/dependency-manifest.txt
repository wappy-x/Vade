- Linux userspace loader, standard library, libc and system linker runtime components.

Installation and boundary:
- Pinned official nightly plus named components and NVPTX target installed user-locally
  with explicit parent authorization. Global default remains existing stable.
- No system package install, driver update, reboot, GPU setting change or service.
- No use of RUSTC_BOOTSTRAP; no manual patching of rustc, LLVM IR or generated PTX.
- Emitted PTX7.0 / sm70 uses default compatible prebuilt core, then driver JIT.
- Genuine Rust device computation is proven. This does not claim a self-authored
  general Rust compiler: rustc, its bundled LLVM, and NVIDIA's JIT remain trusted.
- Library ABI correctness is independently reviewed but not exhaustively verified.
- This is a proof backend, not finished Qwen execution or a qualified inference engine.
