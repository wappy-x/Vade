# Install

[INSTALL.md](../../docs/INSTALL.md) is the single installation entry point for
Vade: start directly on one DGX Spark with `vade launch`, or use a separate
controller with `VADE_CONFIG` and `vade up`.

<a id="3-build"></a>
For prerequisites, pinned toolchains, source or bundle acquisition, verified
FP4-Local weights and build commands, follow
[the on-Spark route](../../docs/INSTALL.md#route-a-on-this-spark).
[First chat on one Spark](../../harness/docs/first-run.md) explains saved local
settings and everyday commands.

<a id="4-download-qwen3-8b"></a>
Older FP8 and Qwen3-8B routes are linked from
[INSTALL](../../docs/INSTALL.md).

Developers should read [AGENTS.md](../../AGENTS.md),
[CONTRIBUTING.md](../../.github/CONTRIBUTING.md) and
[engine validation](validation.md).
