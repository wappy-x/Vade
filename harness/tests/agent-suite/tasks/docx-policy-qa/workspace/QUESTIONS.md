# Questions

Answer each question on its own line in ANSWERS.txt as `Q<N>: <value>`, with
only the value after the colon and one space.

- Q1: How long are audit journals kept? Give the number and the unit, for example `30 days`.
- Q2: Which compression setting do cold snapshots use?
- Q3: What is the largest size of one shard? Give the number and the unit, for example `128 MiB`.
- Q4: What is the name of the primary quorum region?
- Q5: Which role can start an emergency purge?
