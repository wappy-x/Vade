# can stop working after the second read; the agent must read again and
# finish both edits.

  Read src/a.rs and src/b.rs. Then change `SCHEMA_A` in src/a.rs and
  `SCHEMA_B` in src/b.rs from 3 to 4 with workspace_edit_lines. Do not change
  tests/pair.rs. Finish when `cargo test --offline` passes.

check: last-exit-zero
check: unchanged Cargo.toml
check: unchanged tests
check: unchanged src/lib.rs
check: file-equals src/a.rs expected/a.rs
check: file-equals src/b.rs expected/b.rs
