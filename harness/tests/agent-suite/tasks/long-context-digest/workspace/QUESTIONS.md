# Questions about DIGEST.md

DIGEST.md is a digest of the whole tidewater repository. Answer from it.

1. Which file defines the constant `HARBOR_PORT`, and what is its value?
   Answer as the file path, one space, then the value.
2. Which function does `reconcile_ledger` call? Give only its name.
3. What is the value of `RETRY_LIMIT`?
4. How many functions in the digest are marked `#[deprecated]`?
5. How many files does the digest list?

Write the answers to ANSWERS.txt, one line per question, in question order.
Each line is the question number, a colon, one space and the answer. Write
numbers as digits only. Write paths and names with no quotes or backticks.
Write nothing else in the file.
