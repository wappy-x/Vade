# Questions about SPEC.md

Answer each question from SPEC.md, for protocol version 3.

1. What is the default port?
2. What is the largest frame, in bytes?
3. Which message does the client send right after it receives `CHALLENGE`?
4. How many seconds does the client wait before its third retry?
5. Which error code does the server send when a client sends `PULL` with a
   cursor older than 20 days?

Write the answers to ANSWERS.txt, one line per question, in question order.
Each line is the question number, a colon, one space and the answer. Write
numbers as digits only, with no unit. Write message names and error codes
exactly as SPEC.md spells them, with no quotes or backticks. Write nothing
else in the file.
